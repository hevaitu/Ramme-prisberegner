# Faktura-indbakke

Læg nye leverandørfakturaer som PDF her, når priserne i beregneren skal opdateres.

Foreslået arbejdsgang:

1. Gem fakturaen i denne mappe.
2. Skriv til Codex: "Opdater prisberegneren ud fra de nye fakturaer i fakturaer-mappen."
3. Codex udtrækker varelinjer, sammenligner med de nuværende satser og opdaterer beregneren.

Hvis en faktura indeholder varer, der ikke allerede findes i beregneren, skal de normalt godkendes manuelt først. Det gælder især nye rammeprofiler, nye glastyper og nye faste tillæg.
